# Archive

Historical documents that no longer describe the current product — kept for
context on past decisions, not as current guidance. If you're looking for how
TrueKart works today, start at the main [README.md](../../README.md) and
[docs/ARCHITECTURE.md](../ARCHITECTURE.md) instead.

| File | What it was |
|---|---|
| `PRODUCTION-AUDIT.md`, `PRODUCTION-AUDIT-2026.md` | Release-readiness snapshots from v1.7.0, before the "Compare"/"Tools" tabs were removed |
| `EDGE-CASES.md` | Edge-case hardening notes from the v1.7.0 four-tab era |
| `EXTENSION-PLAYBOOK.md`, `SAAS-PLAYBOOK.md` | Pre-v1.8.0 product-strategy planning docs (SerpApi, CLIP, Compare feature) |
| `skills-run/` | Output of an internal AI-agent tooling pass (audits, a PRD, RICE scoring) from 2026-07-02 — working notes, not maintained documentation |

Each archived file that referenced removed functionality has a header noting
what changed and pointing at the current equivalent doc.
